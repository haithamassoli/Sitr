# Sitr Music: خطة إزالة الموسيقى من فيديوهات المتصفح

## تجربة المستخدم المقصودة

1. يثبّت المستخدم تطبيق Sitr كالمعتاد. لا يحتاج إلى Terminal أو Python أو Homebrew.
2. يفتح «Sitr ← الإعدادات ← الموسيقى» ويفعّل الميزة. يبدأ مساعد الصوت المحلي تلقائيًا، ويعود تلقائيًا عند تشغيل Sitr لاحقًا.
3. يضغط «تثبيت إضافة المتصفح» فينتقل إلى صفحة الإضافة في Chrome Web Store ويوافق على التثبيت. هذه الخطوة تحتاج نشر الإضافة أولًا؛ أثناء التطوير نستخدم Load unpacked للاختبار فقط.
4. في صفحة فيديو مدعومة يضغط زر «إزالة الموسيقى» الظاهر على الفيديو. تعرض الإضافة حالات واضحة: تحضير، تنزيل، معالجة، جاهز، أو سبب الفشل. الضغط ثانية يعيد الصوت الأصلي فورًا.
5. الوضع الافتراضي يحتفظ بالصوت البشري فقط. يستطيع المستخدم اختيار الاحتفاظ بالمؤثرات أيضًا، مع توضيح أن بعض الموسيقى قد تبقى. تُعرض حالة اتصال الإضافة بالمساعد المحلي وخطوة إصلاح مباشرة عند توقفه.

## التنفيذ

| مرحلة | العمل | شرط قبول واضح |
|---|---|---|
| 1. إثبات المسار | تكييف إضافة nomusic ومحركه المحلي مع اسم Sitr، مع إبقاء واجهة الفيديو والتزامن والكاش | فيديو تجريبي يعمل بالصوت المعالج، والزر يعيد الأصل؛ اختبارات الإضافة والخادم تمر |
| 2. تثبيت بلا أدوات تطوير | تغليف Python وDemucs وffmpeg ومشغل JavaScript داخل مساعد macOS مستقل؛ تشغيله من Sitr وإيقافه معه. يُضمّن النموذج إذا سُمح بإعادة توزيعه، أو يُنزّل تلقائيًا مرة واحدة بعد موافقة المستخدم | تثبيت DMG على Mac نظيف وتشغيل الميزة بلا Terminal أو تثبيت أدوات تطوير |
| 3. واجهة Sitr | تبويب «الموسيقى»: تشغيل/إيقاف، حالة المساعد، زر تثبيت الإضافة، إصلاح مبسط، شرح للخصوصية والحدود | يستطيع مستخدم غير تقني إكمال الإعداد من واجهتين فقط |
| 4. توزيع الإضافة | تجهيز وصف الأذونات والخصوصية والصور ثم نشرها في Chrome Web Store؛ ربط زر Sitr بعنوانها الحقيقي | التثبيت بنقرة من المتجر، دون Developer Mode |
| 5. تحقق واقعي | تجربة YouTube وفيديو موقع آخر، تقديم/إيقاف/تغيير السرعة، كتم الصوت، تكرار المشاهدة، انقطاع المساعد؛ قياس زمن أول صوت على M1 | لا صوت أصلي عند التفعيل، لا انحراف ملحوظ، ورسائل فشل مفهومة |

## حدود النسخة الأولى

- متصفحات Chromium على macOS؛ Safari يحتاج إضافة منفصلة.
- فيديوهات يمكن للمساعد تنزيل صوتها. البث المباشر والمحتوى المحمي أو المقيد قد يفشل.
- النموذج يفصل مسار `vocals` عن بقية المسارات؛ الغناء قد يبقى، ولا يمكن ضمان إزالة كاملة للموسيقى أو بقاء كل المؤثرات.
- المعالجة محلية، لكن تنزيل المصدر يتصل بموقع الفيديو. يحتفظ المساعد بكاش مؤقت يُحذف بعد سبعة أيام أو يدويًا.
- Sitr الأساسي يظل دون صلاحية شبكة؛ مساعد الصوت تطبيق منفصل بصلاحياته الخاصة. لا يُفعّل أو يبدأ إلا باختيار المستخدم.

## حالة العمل

صدرت الميزة في Sitr 0.2.0. يُنزَّل نموذج htdemucs من خادم Meta الرسمي عند أول استخدام بدل تضمينه، ويُرفق مصدر FFmpeg في
`MusicBackend/THIRD_PARTY_NOTICES.md`. يشرح تبويب «الموسيقى» تثبيت الإضافة في أربع خطوات ويعرض علامة ✓ عند اتصالها. بقي
نشر الإضافة في Chrome Web Store (الملف والوصف جاهزان في `browser-extension/CHROMEWEBSTORE.md`)، ثم وضع رابطها في
`MusicService.storeURL` ليصبح التثبيت بنقرة واحدة.

القياسات على M3 لفيديو مدته 19:26: أول صوت بعد 3.1 ثانية، والمعالجة كاملة في 116 ثانية بمقاطع 7.8 ثانية (مقابل 184 ثانية
بمقاطع 10 ثوانٍ)، بجودة فصل مطابقة للمعالجة الكاملة دفعة واحدة (23.6 مقابل 23.8 dB SDR).

# Source attribution

Sitr Music's browser playback, synchronization, download, and video UI code is adapted from [nomusic](https://github.com/ibraheemtuffaha/nomusic) by Ibraheem Tuffaha and contributors, revision `9cc511f`. The upstream README states the license is MIT but does not include a separate LICENSE file. The MIT permission text is reproduced in [LICENSE.nomusic](LICENSE.nomusic).

Sitr Music changes the extension's name and visuals, simplifies the settings popup, translates the user interface into Arabic, fixes the local helper address, and routes processing requests through the extension worker.

The `third_party/soundtouch/` files are from SoundTouchJS `@soundtouchjs/core@2.0.4` under MPL-2.0. See its [NOTICE.md](third_party/soundtouch/NOTICE.md) and [LICENSE](third_party/soundtouch/LICENSE).
